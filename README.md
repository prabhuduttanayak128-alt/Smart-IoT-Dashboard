# CoreIoT – Smart IoT Monitoring Dashboard

A modern, responsive web-based IoT monitoring dashboard designed to visualize device telemetry, GPS tracking, GSM signal status, and battery performance through an interactive interface.

## 🚀 Features

- **Dashboard Overview:** Monitor key device metrics in one place.
- **GPS Tracking:** Visualize device location using an interactive map.
- **GSM Monitoring:** Display simulated GSM signal strength and network status.
- **Power Analytics:** Track battery levels and visualize power trends.
- **SMS Control:** Interactive SMS control interface with demo message history.
- **Device Settings:** Manage dashboard demo settings and reset demo data.
- **Responsive Design:** Optimized for desktop and mobile screens.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Chart.js
- Leaflet.js
- OpenStreetMap
- Font Awesome

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use the Live Server extension.

## ⚠️ Demo Disclaimer

This project currently uses simulated IoT data for demonstration purposes. GPS coordinates, GSM monitoring, battery telemetry, and SMS interactions are not connected to actual hardware devices.
